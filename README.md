# Seam Carving

A C implementation of content-aware image resizing. Uses pixel-energy calculations and dynamic programming to find and remove minimum-energy vertical seams.

Joint ESC190 project at the University of Toronto with [@Jerry42000](https://github.com/Jerry42000). Code recovered from our [original project repository](https://github.com/Jerry42000/seamcarving). Image I/O helpers (`c_img.c` and `c_img.h`) are course-provided starter files.
